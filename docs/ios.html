Cài nhanh Remote Inside cho iPhone (v0.17.4)

Miễn phí 100% • Dùng vĩnh viễn • Không cần máy tính • Không hết hạn 7 ngày

Bạn đang mở link bên trong ứng dụng khác (Zalo / Facebook / Chrome...) Để tự cài tiện ích và tạo Icon màn hình chính, hãy bấm nút Chia sẻ / ⋯ và chọn Mở bằng Safari, hoặc sao chép link dưới đây dán vào Safari:
1Tải ứng dụng Userscripts (App Store)
Chưa làm

Ứng dụng mã nguồn mở miễn phí của Apple App Store giúp Safari iPhone chạy được Remote Inside như app gốc.

1. Tải app Userscripts miễn phí (App Store)
Hoặc dùng Stay for Safari
2Bật 1 lần trong Cài đặt iPhone
Chưa làm
  • iOS 18+ (iPhone 15 / 16...): Mở Cài đặt → Ứng dụng → Safari → Phần mở rộng.
    iOS 17: Mở Cài đặt → Safari → Phần mở rộng.
  • Gạt BẬT Userscripts → chọn Tất cả các trang web → Luôn cho phép.
  • Quay ra mục Safari → Quyền riêng tư & Bảo mật → gạt TẮT Ngăn chặn theo dõi chéo trang (để SSO FPT không bị chặn), rồi mở app Userscripts lên 1 lần.
3Cài tự động Remote Inside (v0.17.4)
Chưa làm

Bấm nút dưới đây để mở file script gốc trên Safari. Khi màn hình chữ/code hiện ra, bấm biểu tượng 🧩 / AA ở góc trái thanh địa chỉ → chọn Userscripts → bấm Install / Lưu là xong.

3. Cài tự động Remote Inside (v0.17.4)
Tải file .user.js về Tệp

Khi đã cài 1 lần, mọi bản cập nhật mới sau này sẽ tự động nhắc cập nhật qua remote-inside.meta.js.

4Tạo Icon App ngoài màn hình chính
Tùy chọn

Tạo icon Remote Inside màu cam y hệt file APK ngoài màn hình chính (nhấn 1 chạm là mở thẳng Safari với đủ Extension & IAM FPT).

Tải file .mobileconfig vào Tệp

Bấm nút cam xong chọn Cho phép → mở Cài đặt iPhone → Đã tải về hồ sơ → Cài đặt. (Hoặc mở inside.fpt.net rồi bấm Chia sẻ → Thêm vào MH chính).

Mở Remote Inside ngay (nhớ bật VPN công ty)

An toàn thông tin: Hồ sơ tạo icon chỉ chứa đường dẫn inside.fpt.net và hình biểu tượng — tuyệt đối không chứa MDM, không cài chứng chỉ quản trị và xóa được bất kỳ lúc nào.
